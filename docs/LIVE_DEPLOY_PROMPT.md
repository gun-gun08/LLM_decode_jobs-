LESSONS FROM THE LOCAL WORK (avoid these problems)
1. The gateway user cannot link a server action from the rule side: create the base.automation rule first, then create or update the server action with base_automation_id. A new or changed rule is ignored until its active flag is switched off and on. Writing website_published does not fire the rule.
2. In Odoo 19 an Html field value is Markup: markup + str HTML-escapes the str. Build strings with "".join([...]).
3. Public website templates cannot read partners: use .sudo(), otherwise the page gives 403 ("Access Denied by record rules ... res.partner").
4. Shell heredocs mangle backslashes in Python and regex (\b becomes a backspace character, \1 breaks). Write code files with a file-writing tool and scan them for control characters.
5. Upgrading the module: if an older extension view that edits the same element still exists, the new view fails with "cannot be located in parent view": delete the old extension view first. Template or view changes need -u llmd_job_aggregator; Python-only changes need just a restart.
6. If odoo.conf is replaced, keep addons_path with the custom addons folder, or the module is "not found".
7. Odoo 19: there is no --admin-passwd command-line option; models.Constraint replaces _sql_constraints; list views use the list tag.
8. APIs: Adzuna and Jooble return only a snippet of the description; JSearch returns the full text and, when it has one, the employer's own apply link. Jooble's free plan is 500 requests per key in total; JSearch's plans are small (a few hundred requests a month). Indeed and Naukri have no public job-search API (partner feed only). A one-word job title such as "Test" is intentionally not matched to longer listing titles. The filters (experience, job type, work mode, India) are computed from the job text by models/job_facets.py - a job that gives no clue does not match that filter.
9. The old library files (rolelib/install.py, server_action.py, role_library.txt) are for reference only; the module replaces them.
9b. Keep `python -I` OUT of the test commands (isolated mode removes the script folder from the import path); the board test needs the local env variables (ODOO_URL etc.) and runs only against the local instance.
