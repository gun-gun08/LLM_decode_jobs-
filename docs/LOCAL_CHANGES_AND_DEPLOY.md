## 1. Ek nazar mein

- **Live site par abhi:** sirf Recruitment job pages ka chhota automation laga hai (role library se Job Summary, Skills, Responsibilities, Must Have). Naya job board, naya 2-column layout aur Apply Now ke views live par NAHI hain.
- **Localhost par naya:** ek poora Odoo module `llmd_job_aggregator` (v19.0.23.0.0): /jobs par asli jobs ka board - heading "Jobs for your learning path", naya subtitle, search, **course dropdown jo site ke asli course data (eLearning `slide.channel`) se aata hai**, role dropdown, 7 chips, **filters: Location (India default) aur Work mode (All Jobs / Remote / Hybrid / On-site)** (Experience Level aur Job Type filters hata diye), cards par **See Details** (source ka koi naam kahin nahi dikhta), detail page ka shared layout, **detail page par "Apply Now" seedha employer ki job / application page kholta hai (naya tab); click pehle Odoo mein save hota hai (Recruitment > Apply Clicks), koi form nahi** (default); hamara apna application form sirf `llmd_agg.apply_mode = form` karne par aata hai; external portal par jo user type karta hai woh hamare paas kabhi nahi aata (limitation), isliye click se applicant kabhi nahi banta; portal ka applicant data sirf authorized API (X-Api-Key) se aata hai; sync par retries, lock aur log, aur aapki apni positions ka wahi layout.
- **Sources:** Adzuna, JSearch aur Jooble primary hain (Indeed / Naukri sirf official partner feed se). **Jooble ki key `.env` mein hai aur asli API par test ho chuka hai** (India domain `in.jooble.org`; plain + remote + hybrid searches se on-site, remote aur hybrid teeno jobs aati hain). Adzuna aur JSearch ki keys abhi nahi hain. **Himalayas wapas aaya hai - sirf TEMPORARY keyless fallback** (sirf remote jobs): jab baaki sources milkar 20 se kam jobs dein tab padha jaata hai; Jooble ke 157 jobs aate hi wo "Not needed" ho gaya aur uski jobs hide ho gayi (delete nahi), isliye abhi board mein sirf Jooble ki India jobs hain.
- **Live par daalne ke liye:** module ka folder server par copy karke install karna hai (server ya hosting access chahiye). Pehle backup, phir staging.
- **Abhi pending:** Adzuna/Jooble ka asli API test (`local_odoo/.env` mein keys khaali mili) aur Indeed/Naukri ke liye official partner feed.

## 3. Sirf localhost par bana (live par nahi)

**Local setup (sirf test ke liye):** Docker mein `odoo:19.0` + `postgres:16-alpine`, http://127.0.0.1:8070 (8069 par aapka apna Odoo 20 hai), database `llmd_local`, modules `website_hr_recruitment`, `base_automation`, `llmd_job_aggregator`. Files: `local_odoo/` (docker-compose.yml, odoo.conf, setup.ps1, test_local.ps1, env.ps1, .env.example, README.md).

**Module `llmd_job_aggregator` (yahi live par jayega):**

1. **Apni positions (hr.job):** job banne, title / location badalne ya publish hone par best matching asli listing dhoondta hai (Adzuna / JSearch / Jooble, jinki keys hon). Page: left par About the Role, Key Responsibilities, Required Skills, Qualifications, Experience; right par sticky Apply Now card; mobile par card title ke neeche. Hand-written page kabhi replace nahi hota.
2. **Job board /jobs:** asli jobs - **course dropdown site ke course data se (published "training" courses; SOP Library jaise documentation channel aur unpublished course nahi)**, role dropdown (course ke hisaab se, counts ke saath), 7 chips, search, **Location aur Work mode filters** (saath kaam karte hain, reload ke baad yaad rehte hain, pager aur chips mein bhi rehte hain), **India ki jobs pehle**, pager. Aapki published positions upar. Card: title, company, location, tags, "Posted ... ago", **See Details**. Local database mein eLearning nahi hai, isliye yahan sirf fallback ke taur par wahi 4 course naam dikhte hain.
3. **Detail /jobs/ext/ID:** header (title, company, location, salary agar source de, job type), About the Role (chhota), 4 Key Responsibilities, Required Skills, Experience, right par sticky Apply card (ek Apply Now + "View the original posting" link). Har job ki apni ID aur apna link (source + source job id unique). Wahi layout aapki apni positions ka bhi hai (`views/job_view.xml`).
3a. **Apply flow (v19.0.11, abhi default = seedha employer):** (1) **Form mode mein** (`llmd_agg.apply_mode = form`) Apply Now -> `/jobs/ext/ID/apply` form: naam, email, phone (optional), resume (optional, PDF / DOC / DOCX, 5 MB tak, file ka asli content check hota hai), message, consent. Submit par ek savepoint mein: Odoo `hr.applicant` (job ki apni unpublished position ke neeche) + resume attachment + Job Applications record **pehle save**, tab confirmation "received" (signed link). Save fail ho to kuch save nahi hota aur success nahi dikhta. Ek job + ek email = ek hi record; dobara apply karne par duplicate nahi banta; ek browser ghante mein max 30. (2) **Apply Now (default) / "Apply on the employer's website" (form mode)** -> `/jobs/ext/ID/go`: pehle click line save (Recruitment > Apply Clicks: time, job title, company, source, external job ID, apply URL, status), phir 303 redirect original URL par; click mein naam / email / phone nahi, aur click kabhi application nahi. (3) **Limitation (sach):** Jooble, Adzuna, JSearch sirf jobs dete hain; jo user unki / employer ki site par type karta hai woh hamare paas nahi aata. Aisa data sirf kisi provider ke authorized API / webhook / callback se aa sakta hai (jaise ATS ya "Indeed Apply" postback) - abhi connected 3 APIs mein aisa kuch nahi. Hamare system ko jo asli mein milta hai: hamara apna form, Odoo ka apna form (hamari positions), aur API key ke saath bheje applicants (`POST /api/llmd/applications`, `action: applicant`; key khaali = API band). (4) System parameter `llmd_agg.apply_mode`: khaali / `redirect` = **default** (form band, Apply Now seedha employer ki page par, tracked click), `form` = Apply Now hamara form kholta hai (upar (1)). Default mode mein user employer ki site par apply karta hai, isliye uski details hamare paas nahi aati - sirf click line. (5) Job Applications list khud bharti hai: hr.applicant par hook har applicant ka ek record banata hai (website form = "Our website (Odoo form)", backend / e-mail = "Added in Odoo / by e-mail", API = "Job provider (API)"), name / phone / email edit hon to record follow karta hai; status Confirm / Withdraw / Back to Received.
4. **Direct links only (v19.0.14, default ON):** system parameter `llmd_agg.direct_links_only` (khaali / `1` = on, `0` = off). On rehte **Adzuna, Jooble aur Himalayas ko request hi nahi jaati** (status "Off"), kyunki unka link hamesha pehle unka apna page kholta hai; job board link wali job store nahi hoti; unki purani jobs **hide hoti hain, delete nahi** (migration 19.0.14 ne 153 Jooble jobs hide ki). Apni positions jinka saved link job board page hai (jaise Himalayas) ab **apna Odoo application form** `/jobs/apply/<slug>` kholti hain. **Duplicate nahi:** duplicate key = title + company + normalized city (Bangalore = Bengaluru); run mein merge hui job hide hoti hai. Test (2026-10-23): asli fetch, Jooble ko 0 requests (424 -> 424), 294 visible jobs, 0 job board links, 0 duplicates.
4b. **Sources** (menu "Job sources" hata diya; har run ka source-wise result Recruitment > Job board > Sync runs mein): **Company job boards (v19.0.13, key nahi chahiye)** - 42 companies ke apne job boards ki public API (Greenhouse, Lever, Ashby, SmartRecruiters; jaise Databricks, Stripe, MongoDB, Okta, GitLab, Razorpay, Groww, InMobi, CRED, Meesho, Paytm, Zeta, OpenAI, Sarvam AI, Atlan, Freshworks, Bosch, Experian), poora job text, sirf India (ya India se remote) ki woh jobs jo course roles ya 11 job categories mein aayein, har company ki max 100 (v19.0.24 se 81 companies); **Apply Now seedha company ki apni job page par** (beech mein koi job board nahi). Companies ki list system parameter `llmd_agg.company_boards` se badal sakte ho (`provider:board` ya `provider:board=Company name`, comma se alag; `off` = source band; khaali = built-in 81), har company ki jobs `llmd_agg.company_boards_per_board` (100). Naye candidates pehle `rolelib/company_boards_probe.py` se check karo. Phir Adzuna, JSearch, Jooble (keys chahiye), Indeed, Naukri.com (sirf official partner feed) aur Himalayas (keyless, sirf remote, TEMPORARY fallback). Har source ka sach status; jo connected nahi woh kabhi "working" nahi dikhta. Har query teen tarah se bheji jaati hai - plain (India, zyadatar on-site), "remote" aur "hybrid" - taaki Remote, Hybrid aur On-site teeno aayein. Chhote plans bachaye jaate hain: har run mein Adzuna 39, Jooble 9, JSearch 6 searches (roz agle wale), JSearch ka mahine ka budget 150, Jooble ka kul 450.
5. **Data:** normalize, duplicate removal (title + company + jagah), har source ka alag error handling, Jooble ke liye budget guard (450), roz ek baar refresh (scheduled action) aur 'Fetch jobs now' button.
6. **Safety:** sirf http/https links; javascript:, data:, ftp: block; missing description ka saaf message; archived job par 404; description HTML sanitized.

## 5. Live par safely kaise daalein

2. **Staging pehle:** backup ko staging Odoo (wahi version, wahi custom modules) par restore karo aur neeche ke steps pehle wahan chalao.
3. **Module copy:** folder `local_odoo/addons/llmd_job_aggregator` ko live server ke addons path mein copy karo (jahan baaki llmd_* modules hain). `requests` library Odoo ke saath pehle se hoti hai.
4. **Keys:** sirf server ke environment variables mein (`ADZUNA_APP_ID`, `ADZUNA_APP_KEY`, `JOOBLE_API_KEY`) ya Settings > Technical > System Parameters (`llmd_agg.adzuna_app_id` jaise naam). `.env` file live par mat le jao, keys chat mein mat bhejo.
