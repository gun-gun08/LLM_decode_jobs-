2. **Staging pehle:** backup ko staging Odoo (wahi version, wahi custom modules) par restore karo aur neeche ke steps pehle wahan chalao.

4. **Keys:** sirf server ke environment variables mein (`ADZUNA_APP_ID`, `ADZUNA_APP_KEY`, `JOOBLE_API_KEY`) ya Settings > Technical > System Parameters (`llmd_agg.adzuna_app_id` jaise naam). `.env` file live par mat le jao, keys chat mein mat bhejo.
